Las tres composiciones

Arriba, Hoy. Abajo, el registro de sesión. Cada columna es una composición.

A · La pauta
Pelea con la pila de tarjetas redondeadas.
B · El margen
Pelea con el entrenador como una tarjeta o un chat más.
C · La balanza
Pelea con el panel de anillos y métricas que pesan igual.

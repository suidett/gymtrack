# PRD técnico

El PRD vive como documento vivo, con comentarios y ediciones en línea:

https://claude.ai/code/artifact/0b514ac0-d4e6-4bf2-9789-b11dac718ea7

Secciones: resumen, alcance de la versión 1, usuarios y roles, las 20 pantallas, arquitectura y stack, modelo de datos con fórmulas y métodos de progresión, API de 44 endpoints, requisitos no funcionales, plan de construcción en 6 fases y riesgos.

Esta versión 0.1 del código cubre la fase 0 (cimientos) y la parte local de las fases 2 y 3: biblioteca, editor de rutinas, bitácora, cierre con récords y sugerencias, progreso. Lo que exige servidor (cuentas, vínculo con el entrenador, sincronización, fotos, alertas) queda para las fases 1, 3 y 4.

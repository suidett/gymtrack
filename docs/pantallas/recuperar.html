Qué mirar

  • El mensaje de «enlace enviado» no confirma que el correo tenga cuenta («si … tiene una cuenta»): la API responde lo mismo siempre, para no revelar quién está registrado.
  • La hora exacta en que vence el enlace (10:41, una hora después de pedirlo) dice más que «una hora».
  • «Reenviar enlace» espera un minuto entre envíos. Al tercer envío de la hora aparece el límite del PRD (3 por hora por correo).
  • «Abrir correo» abriría la app de correo; el enlace trae de vuelta a «Nueva contraseña». Para ver ese paso y el de enlace vencido, usa el selector de estado.
  • La contraseña nueva usa la misma regla visible que Crear cuenta. No pide repetirla: con «Mostrar» se revisa.
